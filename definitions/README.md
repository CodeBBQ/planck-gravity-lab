# Definitions

This directory establishes the shared mathematical and conceptual vocabulary for
the QuantumGravity project. Every research session must read all files here before
beginning any analysis.

## Contents

| File | Purpose |
|------|---------|
| `planck_scales.md` | Derivations and numerical values of Planck units |
| `what_counts_as_probe.md` | What does "probing Planck-scale physics" actually mean? |
| `common_metrics.md` | Framework for quantifying proximity to the Planck scale |

## Why this matters

Ambiguous vocabulary is a primary source of error in interdisciplinary research.
The distinction between, for example, *measuring a displacement smaller than the
Planck length* and *probing physical processes at the Planck energy* is not merely
semantic — the experimental requirements differ by many orders of magnitude.

Do not use any Planck-scale term without first consulting the relevant definition
file.
