# Literature Claims

Each file in this directory records structured evidence for one topic or paper.

## Naming convention

```
<topic-or-short-paper-label>.md
```

Examples: `atom_interferometry_sensitivity.md`, `ligo_noise_floor.md`

## Required fields per claim

See `LITERATURE_RULES.md` for the complete specification.

```
claim:
value:
conditions:
source:
arxiv_id:
doi:
location:
evidence_code:
verified:
notes:
```
