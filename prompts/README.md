# Prompts

This directory contains reusable prompt templates for AI research sessions.

## Purpose

Prompt templates ensure that new research sessions:

1. Read the mandatory files before starting work.
2. Identify their role and scope.
3. Follow the project rules consistently.
4. Produce output in the expected format.
