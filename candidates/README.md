# Candidates

This directory contains fully developed experimental proposals that have
survived preliminary analysis in the `approaches/` templates.

## Criteria for a candidate experiment

An approach may be promoted to a candidate experiment when:

1. The governing physics has been derived (not merely cited).
2. The signal has been estimated numerically with an explicit derivation.
3. The noise model has been quantified.
4. The orders-of-magnitude gap has been computed using `definitions/common_metrics.md`.
5. Adversarial review has been initiated in `reviews/`.
6. All claims are labelled E1–E4 and trace to accessible sources.

## Files

| File | Experiment | Status |
|------|-----------|--------|
| `TEMPLATE.md` | Required structure for all candidates | Template |

## Adding a candidate

1. Copy `TEMPLATE.md` to a descriptively named file.
2. Fill all required sections.
3. Create a review item in `reviews/adversarial_review.md`.
4. Update `synthesis/comparison_table.md`.
