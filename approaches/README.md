# Approaches

Each file in this directory is a **research template** for one experimental
approach to probing Planck-scale gravitational physics.

## Important

These files are *templates*, not conclusions.  
Do not fill them with premature assessments.  
Each section should be filled in by a dedicated research session following
`PROJECT_RULES.md`.

## Approach files

| File | Approach |
|------|----------|
| `accelerators.md` | High-energy particle accelerators |
| `atom_interferometry.md` | Matter-wave atom interferometry |
| `optical_interferometry.md` | Optical laser interferometry |
| `short_range_gravity.md` | Short-range gravity / fifth-force searches |
| `mechanical_sensors.md` | Mechanical / optomechanical sensors |
| `clocks.md` | Precision atomic clocks |
| `quantum_gravity_experiments.md` | Direct quantum-gravity proposals |
| `astrophysical_baselines.md` | Astrophysical and cosmological baselines |
| `strong_gravity.md` | Strong-gravity environments (BH, NS, pulsars) |

## Template structure

Each approach file follows the template documented below.  
See any approach file for the standard sections.

## Adding a new approach

1. Copy the template from any existing approach file.
2. Name the file descriptively.
3. Record the approach in the table above.
4. Fill sections progressively across research sessions.
