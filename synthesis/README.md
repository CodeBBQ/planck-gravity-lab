# Synthesis

This directory is the endpoint of the provenance chain.  
It integrates surviving candidate experiments into a comparison and final assessment.

## Files

| File | Purpose |
|------|---------|
| `comparison_table.md` | Side-by-side comparison of candidates by proximity metric |
| `final_assessment.md` | Structured final conclusion |

## When to write here

Do not write synthesis conclusions before:

1. At least two approach templates have been completed.
2. At least one candidate experiment has been developed and adversarially reviewed.
3. Dimensional checks have been performed on all key equations.
4. All claims in the candidates have E1/E2 evidence codes.

## Principles

- Present the strongest conclusion supported by evidence, not the most exciting one.
- Negative results are valid.
- If no approach reaches Planck sensitivity, say so with the quantitative gap.
- The final assessment must state explicitly which metrics were used and why.
